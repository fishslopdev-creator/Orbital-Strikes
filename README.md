# Orbital-Strikes

## circle_castle.py

Generates a huge circular island castle schematic (`circle_castle.schem`) with [mcschematic](https://pypi.org/project/mcschematic/):

```
pip install mcschematic
python circle_castle.py -o . -n circle_castle -v JE_1_20_1
```

Paste with WorldEdit about 10 blocks above the ocean surface (`//schem load circle_castle`, `//paste -a`).
